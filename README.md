# Ecommerce-Sales-Analysis-Dashboard-in-Power-BI
**Built an interactive Ecommerce Sales Analysis Dashboard in Power BI**

**Situation:**  
The sales data contained multiple dimensions across time, categories, regions, states, and sub-categories, making performance difficult to assess quickly.

**Task:**  
Create a single dashboard that highlights business performance, YoY growth, category contribution, geographic trends, and top-performing areas.

**Action:**  
I built the solution in Power BI using:
• Dynamic KPI cards for Sales, Profit, Quantity, Orders, and Profit Margin  
• YoY growth measures with conditional indicators  
• Sales vs Profit trend analysis  
• Category and state-level performance views  
• Top 5 states and sub-categories  
• Interactive Year, Region, and Segment slicers  
• A dynamic Performance Insight measure using DAX  

**Result:**  
The final dashboard turns raw ecommerce data into a clear, interactive view of performance and helps users quickly identify growth trends, strong-performing segments, and areas requiring attention.

**A good dashboard should not just present data — it should explain what the data is telling you.**
